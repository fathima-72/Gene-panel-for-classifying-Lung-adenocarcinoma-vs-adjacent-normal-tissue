# Differential-gene---expression-project
This repository contains an ongoing project using  R scripts for performing differential gene expression analysis using the limma package. The workflow includes data processing, model fitting, identification of significant genes, and visualization.

The project demonstrates a standard RNA-SEQ / Microarray analysis workflow, including:
- Data preprocessing
- Experimental design and model fitting
- Identification of significantly differentially expressed genes
- Visualization of results
- Gene annotation of significant results

  This repository will be **updated continuously** as the analysis progresses and additional features are added.

#Tools used:
-R 
-limma
-ggplot2
